# ✅ Modèle — Checklist : installer un nouveau poste

> La procédure standard quand un client ajoute un salarié / change un PC. Suivre dans
> l'ordre garantit qu'aucune étape n'est oubliée.

---

**Client :** ____________  **Utilisateur :** ____________  **Date :** ________
**Nom du PC (convention) :** ____________ (ex : `PC-COMPTA-02`)

## Préparation
- [ ] Vérifier la configuration adaptée à l'usage (métier)
- [ ] Système à jour (Windows Update complet)
- [ ] Nom du poste défini selon la convention du client

## Sécurité
- [ ] Compte utilisateur (sans droits admin) créé
- [ ] Mot de passe conforme + 2FA là où c'est possible
- [ ] Antivirus installé, actif, à jour
- [ ] Pare-feu activé
- [ ] Chiffrement du disque activé (BitLocker) si prévu

## Réseau & accès
- [ ] Connexion au réseau (câble/Wi-Fi) OK
- [ ] IP / DHCP OK (`ipconfig` vérifié)
- [ ] Accès aux dossiers partagés / NAS selon droits
- [ ] Imprimante(s) ajoutée(s)
- [ ] Rattachement au domaine (si PME/AD)

## Logiciels
- [ ] Suite bureautique / messagerie (M365 / Google) configurée
- [ ] Logiciels métier installés + licences
- [ ] Navigateur + favoris utiles

## Données & sauvegarde
- [ ] Données de l'ancien poste migrées (si remplacement)
- [ ] Poste intégré au périmètre de **sauvegarde**
- [ ] Poste intégré à la **supervision / RMM**

## Finalisation
- [ ] Documentation du parc mise à jour (dossier client)
- [ ] Accès enregistrés dans le **coffre à mots de passe**
- [ ] Remise au poste à l'utilisateur + explications
- [ ] Fiche d'intervention remplie
