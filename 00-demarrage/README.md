# 🚀 Démarrage — Par où commencer

Avant de plonger dans les cours, prenons 20 minutes pour **préparer le terrain**.

---

## 1. Ce dont tu as besoin (prérequis)

Rassure-toi, c'est très léger :

- ✅ Un ordinateur (Windows, Mac ou Linux).
- ✅ Une connexion internet (ta box à la maison suffit).
- ✅ De la curiosité. C'est tout.

Tu n'as **pas besoin** d'acheter de matériel pour commencer. On utilisera un
**simulateur** (un logiciel qui imite un vrai réseau sur ton écran).

---

## 2. Comment lire les cours

Chaque cours est un petit fichier `README.md` dans un dossier `cours/XX-...`.

Tu peux le lire :
- Directement sur **GitHub** (clique sur le fichier), ou
- Dans un éditeur de texte comme **VS Code** (gratuit), ou
- Même dans le bloc-notes (c'est juste du texte).

Chaque cours se termine toujours par deux encadrés :
- ✅ **Ce qu'il faut retenir** → les 3 points importants.
- 🔧 **À essayer** → un petit truc à faire toi-même.

> ⚠️ Ne saute pas le « À essayer ». C'est en faisant qu'on retient.

---

## 3. Installer le simulateur (ton bac à sable)

Pour t'entraîner **sans matériel**, on utilise **Cisco Packet Tracer** : un
logiciel gratuit qui te laisse construire des réseaux virtuels (routeur, PC,
câbles…) sur ton écran.

👉 Le guide d'installation complet est ici : [`bac-a-sable/README.md`](../bac-a-sable/README.md)

**Pas maintenant, pas de panique.** Tu l'installeras au Jour 1 du parcours.
Note juste que c'est là.

---

## 4. Installer VS Code (optionnel mais conseillé)

VS Code est un éditeur de texte gratuit, pratique pour lire ce dépôt
confortablement (il affiche joliment le Markdown et les schémas).

1. Va sur **https://code.visualstudio.com**
2. Télécharge la version pour ton système.
3. Installe-la (clique « Suivant » partout, les choix par défaut sont bons).

> 💡 Pour afficher un fichier `.md` en version « jolie » dans VS Code :
> ouvre le fichier, puis appuie sur `Ctrl+Shift+V` (ou `Cmd+Shift+V` sur Mac).

---

## 5. Plusieurs machines ? Organise ton atelier

Si tu as plusieurs ordinateurs (un PC de bureau, un laptop, un Mac…), un petit tuto
t'explique **quelle machine utiliser pour quoi**, et **comment partager des dossiers**
entre Linux, Windows et Mac (utile dès le cours 06) :

👉 [**Tuto — Organiser ton atelier + partage multi-OS**](organiser-son-labo.md)

---

## 6. Les mots compliqués

Dès qu'un mot technique t'échappe, ouvre le [glossaire](../glossaire.md).
Chaque terme y est expliqué **en une seule phrase simple**.

---

## ✅ Ce qu'il faut retenir

1. Pas besoin de matériel : un simulateur gratuit suffit pour commencer.
2. Chaque cours est court et finit par « À retenir » + « À essayer ».
3. En cas de mot inconnu → le glossaire est ton ami.

## 🔧 À essayer

Ouvre le **[Parcours](../PARCOURS.md)** et repère la **Phase 1**. C'est ta feuille de
route : tu la suivras étape par étape. Tu viens de commencer ta formation. 🎉
