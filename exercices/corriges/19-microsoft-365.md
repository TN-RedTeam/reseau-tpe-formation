# Corrigé 19 — Microsoft 365

**1.** M365 = la **boîte à outils complète du bureau, en abonnement** (messagerie,
bureautique, stockage, visio, collaboration). Concurrent principal : **Google Workspace**.

**2.**
- Exchange/Outlook → **messagerie pro**.
- OneDrive → **stockage personnel** en ligne.
- SharePoint → **espaces de fichiers partagés** d'équipe.
- Teams → **chat, visio, collaboration**.
- Entra ID → **comptes centralisés**.

**3. (piège)** **OneDrive = tiroir personnel** ; **SharePoint = armoire commune d'équipe**.
Règle : **document perso → OneDrive ; document d'équipe → SharePoint**.

**4.** Par ex. : créer/supprimer des comptes, gérer les **licences**, configurer la
messagerie, créer les espaces SharePoint/Teams, sécuriser. Trois suffisent.

**5.** Le **MFA / 2FA pour tous** (surtout les admins). Parce qu'un compte piraté sans MFA
donne accès à toute la messagerie et aux fichiers ; le MFA bloque l'essentiel des attaques.

**6.** Parce que Microsoft protège **son infrastructure**, pas tes **erreurs** (suppression,
piratage, rançongiciel) : d'où une **sauvegarde tierce** (rappel cours 18).

**7.** (pratique) Tu dois repérer : créer un utilisateur, attribuer une licence, activer le
MFA.
