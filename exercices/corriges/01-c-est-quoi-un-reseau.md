# Corrigé 01 — C'est quoi un réseau ?

**1.** Un réseau, c'est **plusieurs appareils reliés entre eux pour échanger des
informations**.

**2.** Le routeur = **le gardien de l'immeuble** (ta box). Il gère les entrées/sorties
et oriente les informations.

**3.** Le **réseau local (LAN)** = les appareils proches, reliés à ta box (ton
« immeuble »). **Internet** = le réseau mondial, « la ville entière ». Le LAN se
connecte à internet **via la box**.

**4.** Par exemple : **partager des fichiers**, **partager une imprimante**, **aller
sur internet** (ou : sauvegarder sur un NAS). Trois suffisent.

**5.** Le point central est la **box (le routeur)** : tout passe par elle.

**6.** (réponse personnelle) Tu as sûrement trouvé plus d'appareils que prévu :
PC, téléphones, TV, imprimante, enceintes, montre connectée… Tout ça forme ton
réseau local.
