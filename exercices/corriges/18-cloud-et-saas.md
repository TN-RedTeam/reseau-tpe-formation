# Corrigé 18 — Le cloud & le SaaS

**1.** Local = **posséder sa voiture** ; cloud = **taxi/autopartage** (payer à l'usage un
service entretenu par un autre). Sans la magie : le cloud, ce sont **les ordinateurs de
quelqu'un d'autre**, utilisés via internet.

**2.** **SaaS** = un **logiciel** prêt à l'emploi ; **PaaS** = une **plateforme** de
développement ; **IaaS** = des **machines** (serveurs loués). En TPE/PME, surtout du
**SaaS**.

**3.** Avantages : travailler de partout, collaboration, moins de matériel, MAJ auto.
Vigilance : **dépendance à internet**, **données chez un tiers (RGPD)**, **sauvegarde non
incluse**.

**4. (important)** **FAUX.** Le fournisseur garantit **son infrastructure**, pas **tes
erreurs** : suppression, compte piraté, rançongiciel… se perdent. Il faut une **sauvegarde
tierce** (règle 3-2-1).

**5.** Parce que les données peuvent être **hors d'Europe** : pour le RGPD (cours 20), il
faut privilégier un **hébergement UE** avec garanties.

**6.** (réponse personnelle) L'important : identifier **où** sont les données et **le risque
de suppression**, qui justifie une sauvegarde.
